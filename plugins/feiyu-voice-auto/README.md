# 肥鱼概率语音

设置 → 工具与技能 →「肥鱼概率语音」→ 设置 →「语音调用概率（0–100%）」。默认20%，0关闭自动语音，100表示符合条件时全部使用语音。可以使用设置弹窗自带的会话范围，限定群聊或私聊。

概率按每次模型回复会话抽样一次，抽中后把模型准备发送的短文字改为肥鱼语音；不会把思考内容或未决定发送的草稿播出去。声线、最长字数及冷却时间沿用「肥鱼本地语音」的设置（默认cute、50字、1分钟）。冷却或忙碌期间、长文字、引用、@、链接和代码保持原文字，不进入抽样。

多条短气泡在总长度允许时合并为一句语音。成功后不重复发送文字；合成或编码失败则发送原来的文字。一次回复会话抽样未命中后不反复重抽。模型明确调用肥鱼或曼波语音的回复会话跳过自动语音。

关闭任意一个肥鱼扩展，或将对应会话排除，都会阻止自动语音；合成期间关闭概率插件也会阻止语音发送，保留原文字回复。

实现使用 `message.deliver-text` 扩展点，覆盖原生工具调用、内联工具解析及回复恢复流程最终执行的 `send_message`。跨会话 `send_to` 保持原行为。发送继续经过原有队列、限频、权限与留档。

依赖本机肥鱼服务 `http://127.0.0.1:9880` 和「肥鱼本地语音」技能。概率策略在插件里执行，不要求模型自行随机决定。改概率后立即生效，不需要重启；首次加入核心发送扩展点需要重启一次。

验证：`node test/feiyu-voice-auto-test.mjs`，使用模拟发送端，不向QQ发送消息。

设置弹窗显示实时本地服务状态，并提供「启动本地语音服务」和「重新检测服务」。启动仅加载现有模型，后台进程独立运行，不含开机自启。
