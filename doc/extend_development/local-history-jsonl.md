# Local History and Meme Memory

Raw messages are stored under `DATA_DIR/messages-jsonl/group_<id>/YYYY-MM-DD.jsonl` (or `private_<id>`). Dates use Asia/Shanghai. Each line is a versioned event with a per-chat sequence: message upserts, deletions and next-ID metadata. Read flags and recalls are persisted as updates. Backfills are assigned their original message date; replay orders events by sequence so late backfills cannot resurrect deleted messages.

Existing `messages/*.json` files are automatically imported into a staging directory, replayed and compared before the directory is installed. Old JSON is retained as a read-only migration backup. Once `format.json` exists, the JSONL journal is authoritative: old files are never used to resurrect messages. Never run an old JSON-writing app concurrently with migration or the new app. Use one process per data directory. Corrupt interior JSONL lines fail closed; a torn final line is preserved separately before repair.

`node scripts/migrate-chat-jsonl.mjs` migrates all known chats and saves a count report. Set `QQ_AGENT_DATA_DIR` to the actual runtime directory first. `node scripts/summarize-chat-days.mjs` backfills daily summaries for allowed chats only; this calls the configured LLM, keeps source IDs, processes 100-message increments, and never sends QQ messages.

Daily summaries live in `daily-summaries/<chat>/YYYY-MM-DD.json`. With `store.historySummary.enabled=true`, context contains at most three local-calendar days of summaries (900 characters each), 20 recent originals and up to 10 unsummarized recent messages. Raw archives are not deleted after three days. Summaries may omit details; `search_chat_history` retrieves source messages by dates, keyword or sender, while `get_daily_summary` incrementally summarizes any archived date. A generation failure leaves raw data untouched and does not fabricate a summary.

Context building reads cached summaries immediately and schedules at most one missing/stale day in the background; it never waits for generation. A background worker completes previous-day summaries every ten minutes with a three-request budget. Current-day summaries refresh after ten new messages. Shutdown waits for pending summary jobs. Calls are isolated, have a 60-second timeout, and explicitly disable reasoning. Dates older than three days remain on disk and are not injected by default.

The `group-memes` skill stores per-chat records under `memes/<chat>.json`. Writes require real message IDs and a verbatim evidence quote. Source-backed means evidence exists, not that the LLM's interpretation is guaranteed true. Unconfirmed records stay labeled. Recalls, source changes and deletions invalidate derived records; blocked sources are excluded and invalidated upon access. Retrieval is chat-bound and has bounded output; the whole meme library is never put in the system prompt.

Deletion events hide messages from all current reads but do not physically erase earlier JSONL events or migration backups. Secure erasure requires separately removing backups and compacting the journal while stopped. Do not commit runtime data, exports or generated summaries. Different machines should use separate data directories and never concurrently write a shared journal.
