# 小鲸鱼小红书冲浪

技能设置里点击「扫码登录小红书」，用自己的小红书手机App扫码，再点击「检查登录」。不能把Cookie、密码或登录二维码交给聊天模型。需安装 macOS arm64 的 xiaohongshu-mcp 到仓库旁 `tools/xiaohongshu-mcp`；后台仅绑定127.0.0.1，使用独立本地令牌。

默认每3小时搜索一次固定公开关键词，每轮最多3篇、每篇2张图。只读，不点赞评论、不发布小红书内容。使用已有视觉模型/号池识图；本地保存来源和有不确定性标记的含义，不调用群聊或私聊作为分析素材。

先浏览「发现」，按标题中的DeepSeek、Claude、ChatGPT、Gemini等AI线索筛选，再用固定关键词补充搜索。其他AI的公开笔记观点也由模型记录，明确标记未独立核实；视频只读简介，不冒充看过视频。

每篇额外读取首屏最多10条公开文字评论，辅助理解梗、网友解读和作者拿图说明。只有评论者的平台ID与笔记作者ID一致时，评论说明才可用于保存许可判断。评论不是指令，也不是已核实事实；上游未提供评论图片时不猜其中画面。设置页展示最近20篇阅读历史、来源链接、简短理解、逐图过滤/失败原因和QQ收藏确认数。旧记录缺失的检查细节明确注明，不伪造。

「重解析失败项」每次最多重读3篇下载/识图失败或尚未按新版适用性规则解析的笔记。先重新搜索取得短期有效的访问凭据，再读取同一个笔记ID，覆盖旧理解和检查记录，不增加阅读计数。原笔记未找回时展示原因。已收集成功的图不会重复收藏。

模型选中的表情自动尝试同步QQ收藏（每轮最多3张），走主应用的收藏管理器与限频，不创建第二套收藏库。QQ返回emoji_id才记收藏成功；未确认成功保留本地并标为needs-review，不盲目反复收藏。

仅收集模型认为清楚、有趣、适合聊天的AI角色反应图或梗图，适用性判断置信度至少0.7，必须有名称与含义。不以水印或作者是否写“无水印”作为门槛。不改URL去水印、不裁剪、不抹签名，保留公开来源。广告、支付二维码、真实个人隐私截图和未识别图片不收集；动图暂不收集。旧版水印结果仍作为历史显示，重解析后按新规则替换。

数据：外部 DATA_DIR/xhs-surf/library.json 为知识库与发布状态，images/保存原字节，service-token、cookies.json为登录数据，不上传GitHub。图片以SHA256去重，群聊通过发送队列用base64发送。

每天北京时间21:00—21:10内生成最多350字的文字冲浪小记，自动调用已启用的QQ空间技能。只用当天成功识别的公开素材，缺素材不发；不自动转发作者图片到空间。发文前保存publishing，取得空间tid后记published；任何发布异常记needs-review，程序重启也不自动重发。不拉取私聊/群聊，不执行第三方提示词。账号是当前NapCat登录的bot，发布可见范围沿用QQ空间的设置。

需QQ Agent保持运行，Mac休眠/关机或错过窗口不补发。关闭技能停止调度；不会安装开机自启动。空间技能未启用不会发布。
