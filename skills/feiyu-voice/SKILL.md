# 肥鱼本地语音

本机声音服务地址固定为 `http://127.0.0.1:9880`，使用上游 `/v1/speech` 异步任务协议。
密钥从项目旁 `feiyu/.runtime/voice-service/api_key.txt` 读取，不进入提示词。

调用 `feiyu-voice__send_voice`，传入 `text`、`style=cute|gentle`、`requested=true`。
默认只在用户明确要求时发送，最多50字，每会话间隔1分钟。可在技能设置调整。
合成任务最多等待10分钟；失败不宣称已发送，不立即重复提交超时任务。

音频缓存位于 `DATA_DIR/feiyu-voice`；缓存区分两种声线，重用相同文案。
WAV 使用现有 `encodeQqVoice` 转为 SILK，通过发送队列发送 OneBot `record`。
模型在本地执行，生成后才通过 QQ 发送；此工具不提供语音转文字、换声或唱歌。

先运行项目旁的 `feiyu/macos/start.sh` 启动服务。具体部署与试听命令见 `feiyu/macos/README.md`。

本机服务当前默认采用常驻 MLX 后端，接口和工具参数保持一致。完整 HTTP 请求包含动态文本前端处理；模型与两种参考音频特征在服务启动时预加载。
MPS 和 CPU 可按 `feiyu/macos/README.md` 切回。相同文案的旧音频缓存仍可复用；性能验收使用 `smoke-qq.mjs --fresh` 强制走真实服务。

自动概率语音由确定性插件 `feiyu-voice-auto` 控制（默认20%，可配置0–100%），使用本技能提供的内部能力；本技能的“允许主动语音回复”仍只控制模型直接调用语音工具，不必为概率插件打开它。自动语音沿用本技能的声线、字数和冷却设置。手动调用成功也会记录到会话发送历史，避免重复回复。

语音文案按中文空格/换行、中英文逗号、句末标点分句，逐句合成后按原顺序拼成一条语音。英文单词间空格和数字小数点保留。分句之间留约180毫秒停顿，句末约260毫秒；只发送最终完整音频，一段失败则整条按原有规则回退。最多两个HTTP请求同时在途，MLX GPU仍在单线程队列串行推理。合成总时长最多30秒；分句和拼接结果分别缓存，旧整句缓存不会覆盖新拼接结果。

每个分句合成后使用保守的声学首尾降噪：10毫秒能量帧检测持续人声，保留起音前160毫秒和尾音后200毫秒缓冲，对更远的弱声区最多衰减18dB，边界6毫秒淡入淡出。人声主体不做频谱削减、不裁剪时长。原始WAV缓存保留，处理后音频使用独立版本缓存。它针对首尾弱噪声与边界突变，不保证去除人声中间的杂音；需要试听确认。

拼接时先裁掉分句首尾过长的静音/弱噪声，保留起音前80毫秒、尾音后120毫秒缓冲，并对新边界淡入淡出；不裁句中停顿。标点停顿按总间隔计算，扣除相邻两段保留的缓冲，不叠加静音。常见空格/逗号连接约200毫秒，句末约260毫秒；不是语义VAD，轻声起尾仍需试听确认。未检测到持续人声时保留音频，不猜测裁剪。时长处理缓存另有版本，不复用旧长空白拼接音频。

跨机器同步与 Windows 依赖见 `doc/windows-sync.md`。可用环境变量 `QQ_AGENT_FEIYU_ROOT` 指定本机部署根目录；Windows 需手动启动服务，设置页仍可检测连接，Mac MLX 启动脚本不可用于 Windows。
